# Divisionary Numbers
## A Proposed Numerical System for Representing Division by Zero Without Collapsing Distinct Quotients

**Author:** Shatadru Bose  
**Concept:** Divisionary Numbers  
**Notation:** `d`  
**Core definition:** `xd = x/0`

---

# Abstract

Division by zero is one of the most important forbidden operations in conventional arithmetic. In ordinary real-number arithmetic, expressions such as

\[
\frac{1}{0},\quad \frac{2}{0},\quad \frac{5}{0},\quad \frac{100}{0}
\]

are undefined. The reason is not merely that the answers are "too large" or "infinity." Rather, there is no ordinary number that can satisfy the corresponding multiplication equation.

The Divisionary Number system is a proposed mathematical notation designed to represent these expressions **without pretending that conventional division by zero has been solved**.

The central idea is to preserve every numerator as a distinct divisionary value:

\[
1d=\frac{1}{0}
\]

\[
2d=\frac{2}{0}
\]

\[
5d=\frac{5}{0}
\]

\[
100d=\frac{100}{0}
\]

Thus, instead of forcing every nonzero division-by-zero expression into a single object such as infinity, Divisionary Numbers retain the identity of the numerator.

A particularly important rule of the proposed system is:

\[
0d=0
\]

corresponding to the special convention

\[
\frac{0}{0}=0.
\]

This convention is **not part of ordinary arithmetic**. It is an explicit axiom of the proposed Divisionary Number system.

The system therefore does not claim that division by zero becomes valid in conventional arithmetic. Instead, it introduces a new symbolic domain in which expressions traditionally regarded as undefined can be represented as distinct objects.

The most important principle of the system is:

> **A Divisionary Number represents a division-by-zero expression; it does not claim to solve that expression inside ordinary arithmetic.**

This distinction allows the system to preserve information that would otherwise be discarded.

---

# 1. Introduction

Division is normally understood as the inverse of multiplication.

For example,

\[
\frac{10}{2}=5
\]

because

\[
5\times2=10.
\]

Similarly,

\[
\frac{21}{7}=3
\]

because

\[
3\times7=21.
\]

The denominator therefore plays a fundamental role.

When the denominator is zero, conventional arithmetic encounters a fundamental problem.

Consider:

\[
\frac{5}{0}.
\]

If we attempt to interpret this as an ordinary number \(x\), we would require

\[
x\times0=5.
\]

However, for every ordinary number \(x\),

\[
x\times0=0.
\]

Therefore,

\[
x\times0=5
\]

has no solution in ordinary arithmetic.

Consequently,

\[
\frac{5}{0}
\]

is undefined.

The same argument applies to every nonzero numerator:

\[
\frac{1}{0},
\frac{2}{0},
\frac{3}{0},
\frac{4}{0},
\ldots
\]

None of these expressions has an ordinary real-number solution.

The Divisionary Number concept approaches this problem differently.

Instead of asking:

> "What ordinary number equals \(5/0\)?"

the system asks:

> "Can we create a distinct symbolic object that records the expression \(5/0\) without claiming that ordinary division has been solved?"

The proposed answer is yes.

That object is written as:

\[
5d.
\]

---

# 2. The Fundamental Definition

The defining rule of Divisionary Numbers is:

\[
\boxed{xd=\frac{x}{0}}
\]

where \(x\) is the numerator.

The symbol `d` can be understood as the **divisionary suffix**.

Therefore:

\[
1d=\frac{1}{0}
\]

\[
2d=\frac{2}{0}
\]

\[
3d=\frac{3}{0}
\]

\[
4d=\frac{4}{0}
\]

\[
5d=\frac{5}{0}
\]

and so on.

For arbitrary \(x\),

\[
xd=\frac{x}{0}.
\]

The important feature is that the numerator is not discarded.

---

# 3. Why Not Simply Use Infinity?

A common response to division by zero is to write:

\[
\frac{1}{0}=\infty.
\]

However, this creates several conceptual problems.

Consider:

\[
\frac{1}{0}
\]

and

\[
\frac{1000}{0}.
\]

If both are simply identified with the same infinity symbol,

\[
\frac{1}{0}=\infty
\]

and

\[
\frac{1000}{0}=\infty,
\]

then the original numerators are no longer represented in the result.

The Divisionary Number system instead preserves the distinction:

\[
\frac{1}{0}=1d
\]

while

\[
\frac{1000}{0}=1000d.
\]

Thus:

\[
1d\ne1000d.
\]

The system does not collapse all nonzero division-by-zero expressions into one object.

---

# 4. Divisionary Numbers as Tagged Quotients

A useful way to understand the notation is as a **tagged quotient**.

Normally,

\[
\frac{x}{y}
\]

contains two pieces of information:

- numerator \(x\),
- denominator \(y\).

For ordinary division with nonzero denominator, the result can usually be reduced to another number.

For example:

\[
\frac{20}{5}=4.
\]

The original numerator and denominator disappear into the result.

For division by zero, however, the proposed system deliberately preserves the numerator.

Thus:

\[
\frac{x}{0}\longrightarrow xd.
\]

The suffix `d` effectively communicates:

> "This object represents the numerator \(x\) divided by zero."

Therefore `d` is not simply another mathematical constant.

It is a **classification marker**.

---

# 5. Basic Divisionary Table

The first several Divisionary Numbers are:

| Expression | Divisionary form |
|---|---|
| \(0/0\) | \(0d=0\) |
| \(1/0\) | \(1d\) |
| \(2/0\) | \(2d\) |
| \(3/0\) | \(3d\) |
| \(4/0\) | \(4d\) |
| \(5/0\) | \(5d\) |
| \(6/0\) | \(6d\) |
| \(7/0\) | \(7d\) |
| \(8/0\) | \(8d\) |
| \(9/0\) | \(9d\) |
| \(10/0\) | \(10d\) |
| \(100/0\) | \(100d\) |
| \(1000/0\) | \(1000d\) |

The key special case is:

\[
\boxed{0d=0}
\]

while for nonzero \(x\),

\[
\boxed{xd\ne0}.
\]

---

# 6. The Special Zero Rule

The proposed system contains a special rule:

\[
\boxed{\frac{0}{0}=0}
\]

and therefore:

\[
\boxed{0d=0}.
\]

This is a deliberate convention.

It is important to distinguish this from standard mathematics.

In conventional real arithmetic,

\[
\frac{0}{0}
\]

is undefined.

It is an indeterminate form in many contexts and does not have a unique value.

The Divisionary Number system chooses a different axiom:

\[
0d=0.
\]

This does not mean conventional mathematics has discovered that \(0/0=0\).

It means that the proposed Divisionary Number framework **defines its own behavior for the special case**.

---

# 7. Why \(0/0\) Is Different

The expression

\[
\frac{0}{0}
\]

is fundamentally different from

\[
\frac{5}{0}.
\]

For \(5/0\), attempting to solve

\[
x\times0=5
\]

fails because the left side is always zero.

For \(0/0\), attempting to solve

\[
x\times0=0
\]

does not identify a unique \(x\).

Every ordinary number satisfies:

\[
x\times0=0.
\]

For example:

\[
1\times0=0
\]

\[
2\times0=0
\]

\[
100\times0=0
\]

\[
-7\times0=0.
\]

Thus \(0/0\) does not naturally determine one ordinary numerical answer.

The Divisionary Number system nevertheless chooses the convention:

\[
0d=0.
\]

This makes zero a special member of the proposed system.

---

# 8. The Divisionary Number Set

A simple formalization can define a Divisionary domain as

\[
D=\{xd\mid x\in\mathbb{R},x\ne0\}\cup\{0\}.
\]

In words, \(D\) contains:

1. the ordinary zero;
2. a distinct Divisionary Number \(xd\) for every nonzero real number \(x\).

Examples include:

\[
1d,\;2d,\;3d,\;-1d,\;-2d,\;0.5d,\;\pi d,\;\sqrt2d.
\]

The system could therefore contain infinitely many Divisionary Numbers.

---

# 9. The Identity of a Divisionary Number

The defining identity is:

\[
xd=\frac{x}{0}.
\]

Therefore the numerator is part of the identity.

If

\[
xd=yd,
\]

then the proposed system can impose the equality rule:

\[
\boxed{xd=yd\iff x=y}.
\]

Thus:

\[
5d=5d
\]

is true.

But:

\[
5d=6d
\]

is false.

Similarly:

\[
1d\ne2d
\]

and

\[
100d\ne101d.
\]

This gives Divisionary Numbers their distinguishing feature.

---

# 10. Divisionary Numbers Are Not Infinity

It is crucial not to define

\[
1d=\infty.
\]

Instead:

\[
1d
\]

is its own symbolic object.

Likewise:

\[
5d
\]

is not necessarily equal to infinity.

The distinction can be expressed as:

\[
\boxed{xd\ne\infty}
\]

unless a separate mathematical structure explicitly defines such a relationship.

The purpose of `d` is not to create another spelling for infinity.

Its purpose is to preserve the exact numerator of a division-by-zero expression.

---

# 11. Divisionary Numbers and Undefinedness

An important philosophical feature of the proposal is that it does not necessarily eliminate the concept of undefinedness.

Instead, it can preserve two different concepts:

### Conventional undefinedness

\[
\frac{5}{0}
\]

has no ordinary real-number value.

### Divisionary representation

\[
\frac{5}{0}\mapsto5d.
\]

Therefore the system can say:

> \(5/0\) is undefined as an ordinary real number, but it has a Divisionary representation \(5d\).

This is a much more precise statement than simply claiming that division by zero has been solved.

---

# 12. Representation Versus Evaluation

This distinction is central to the entire theory.

Suppose:

\[
5/0.
\]

There are two possible operations:

### Evaluation

Try to calculate the quotient as an ordinary number.

This fails.

### Representation

Create a symbolic object representing the expression.

The proposed system performs the second operation.

Thus:

\[
\frac{5}{0}\rightarrow5d
\]

does not necessarily mean:

\[
5d=5.
\]

It means:

\[
5d\text{ represents }5/0.
\]

This distinction prevents many contradictions.

---

# 13. Why the System Does Not "Solve" \(5/0\)

Suppose someone asks:

\[
\frac{5}{0}=? 
\]

Under ordinary arithmetic, the answer is:

\[
\text{undefined}.
\]

Under the proposed notation, one may write:

\[
\frac{5}{0}=5d.
\]

However, `5d` should not automatically be treated as an ordinary real number.

It is better interpreted as:

\[
\boxed{\text{Divisionary representation of }5/0}.
\]

The expression remains outside the ordinary real-number result set.

---

# 14. Why This Can Be Better Than Forcing an Answer

There is a major mathematical advantage to preserving undefined expressions instead of forcing them into ordinary numbers.

Suppose we arbitrarily declared:

\[
\frac{5}{0}=0.
\]

Then we would have:

\[
5/0=0.
\]

But multiplication-based verification would require:

\[
0\times0=5,
\]

which is false.

If instead we declared:

\[
5/0=5,
\]

we would require:

\[
5\times0=5,
\]

which is also false.

Therefore, assigning an ordinary number to \(5/0\) destroys the ordinary inverse relationship between multiplication and division.

The Divisionary approach avoids this problem by refusing to pretend that `5d` is an ordinary quotient.

---

# 15. The Fundamental Principle

The entire proposal can be summarized by one principle:

\[
\boxed{\frac{x}{0}\text{ is represented by }xd,\text{ not solved as an ordinary number.}}
\]

This preserves information without violating the ordinary multiplication law.

---

# 16. Positive Divisionary Numbers

For positive \(x\),

\[
xd
\]

can be called a **positive Divisionary Number**.

Examples:

\[
1d,\;2d,\;3d,\;4d,\;5d.
\]

The numerator determines the identity.

For example:

\[
7d=\frac70.
\]

It does not mean that the result is seven.

---

# 17. Negative Divisionary Numbers

The same notation can be extended to negative numerators:

\[
-1d=\frac{-1}{0}
\]

\[
-5d=\frac{-5}{0}
\]

\[
-100d=\frac{-100}{0}.
\]

The sign belongs to the numerator.

Therefore:

\[
5d\ne-5d.
\]

If equality is based on the numerator identity, then:

\[
xd=yd
\]

only when

\[
x=y.
\]

---

# 18. Fractional Divisionary Numbers

The system can also represent fractional numerators.

For example:

\[
\frac12d=\frac{\frac12}{0}.
\]

Similarly:

\[
0.25d=\frac{0.25}{0}.
\]

And:

\[
\pi d=\frac{\pi}{0}.
\]

Therefore Divisionary Numbers do not need to be restricted to integers.

They can potentially correspond to every nonzero real numerator.

---

# 19. Irrational Divisionary Numbers

Irrational numbers can also be used as numerators.

For example:

\[
\sqrt2d=\frac{\sqrt2}{0}.
\]

Likewise:

\[
\pi d=\frac{\pi}{0}
\]

and

\[
ed=\frac{e}{0}.
\]

If the equality rule is based on numerator identity, then:

\[
\pi d\ne ed
\]

because

\[
\pi\ne e.
\]

---

# 20. Complex Divisionary Numbers

A possible future extension is to allow complex numerators.

For example:

\[
id=\frac{i}{0}
\]

where \(i^2=-1\).

Likewise:

\[
(3+2i)d=\frac{3+2i}{0}.
\]

This would create a broader Divisionary extension over the complex numbers.

However, such an extension would require careful definitions of ordering, multiplication, conjugation, and other operations.

---

# 21. Divisionary Numbers as an Extension

One possible notation is:

\[
\mathbb{R}_d
\]

for the proposed Divisionary extension of the real numbers.

A conceptual model could be:

\[
\mathbb{R}_d
=
\mathbb{R}\cup D
\]

where

\[
D=\{xd:x\in\mathbb{R},x\ne0\}.
\]

The important point is that the new objects are not simply ordinary real numbers.

They are tagged objects.

---

# 22. A Tagged-Pair Interpretation

A rigorous way to formalize the idea is to regard a Divisionary Number as a pair.

Instead of thinking of

\[
5d
\]

as a mysterious new numerical quantity, define:

\[
5d=(5,\text{divisionary}).
\]

Then:

\[
7d=(7,\text{divisionary}).
\]

Consequently:

\[
5d\ne7d.
\]

This interpretation makes the proposal much easier to formalize computationally.

---

# 23. Divisionary Numbers in Computer Science

The concept is particularly interesting from a programming perspective.

A programming language could represent a Divisionary Number as a tagged object.

For example, conceptually:

```text
Divisionary(5)
```

would represent:

```text
5 / 0
```

while:

```text
Divisionary(100)
```

would represent:

```text
100 / 0
```

The values would remain distinguishable.

This resembles the general programming concept of a **tagged value** or **sum type**.

Instead of returning an ordinary numeric value, a division operation could return a value whose type indicates that it is Divisionary.

---

# 24. A Possible Type System

A programming language could theoretically define:

```text
Number
├── Integer
├── Float
├── Complex
└── Divisionary
```

For example:

```text
5 / 0
```

could return:

```text
Divisionary(5)
```

while:

```text
0 / 0
```

could return:

```text
0
```

under the proposed special rule.

This would allow software to preserve the distinction between:

```text
Divisionary(1)
Divisionary(5)
Divisionary(100)
```

rather than converting all of them to the same error or infinity value.

---

# 25. Comparison With Floating-Point Infinity

IEEE-style floating-point arithmetic commonly has special values such as:

\[
+\infty
\]

and

\[
-\infty.
\]

But Divisionary Numbers are conceptually different.

A simplified comparison is:

| Concept | Meaning |
|---|---|
| \(+\infty\) | Positive infinity |
| \(-\infty\) | Negative infinity |
| NaN | Not-a-Number |
| Undefined | No ordinary result |
| \(5d\) | Representation of \(5/0\) |
| \(100d\) | Representation of \(100/0\) |

The defining difference is that Divisionary Numbers preserve the numerator.

---

# 26. Divisionary Numbers Versus NaN

`NaN` means "Not a Number."

It is commonly used in computing for invalid numerical results.

For example, floating-point systems may represent certain invalid operations using NaN.

However, NaN normally does not preserve exactly which numerator produced the invalid operation.

For example, a system might treat both:

```text
5 / 0
```

and another invalid expression as exceptional results.

The Divisionary proposal instead records:

```text
5d
```

for the first expression.

Thus the information is preserved.

---

# 27. Divisionary Numbers Versus Undefined

"Undefined" is a status, not necessarily a numerical object.

For example:

\[
\frac{5}{0}
\]

can be described as undefined in ordinary arithmetic.

The Divisionary proposal adds a representation layer:

\[
\operatorname{Div}(5)=5d.
\]

Thus:

\[
\boxed{\text{undefined as an ordinary quotient}\ne\text{unrepresentable expression}}
\]

This distinction is one of the strongest conceptual features of the idea.

---

# 28. The Zero Divisionary Number

Under the proposed special rule:

\[
0d=0.
\]

This makes zero exceptional.

The system could therefore define:

\[
\operatorname{Div}(x)=
\begin{cases}
0,&x=0\\
xd,&x\ne0
\end{cases}
\]

where:

\[
\operatorname{Div}(x)
\]

means "the Divisionary representation of \(x/0\)."

Thus:

\[
\operatorname{Div}(0)=0
\]

but:

\[
\operatorname{Div}(1)=1d.
\]

---

# 29. The Divisionary Mapping

Define a mapping:

\[
\delta(x)=
\begin{cases}
0,&x=0,\\
xd,&x\ne0.
\end{cases}
\]

Then:

\[
\delta(0)=0
\]

\[
\delta(1)=1d
\]

\[
\delta(2)=2d
\]

\[
\delta(5)=5d.
\]

This gives a mathematical mechanism for generating Divisionary representations.

---

# 30. Injectivity of the Nonzero Part

For nonzero values, the mapping can be injective.

That means:

\[
\delta(x)=\delta(y)
\]

implies:

\[
x=y.
\]

Therefore:

\[
1d\ne2d
\]

and:

\[
5d\ne10d.
\]

This formalizes the fundamental requirement that every numerator remain distinct.

---

# 31. Addition of Divisionary Numbers

If the system is to become a complete algebraic structure, addition must be explicitly defined.

One possible rule is:

\[
xd+yd=(x+y)d
\]

provided:

\[
x+y\ne0.
\]

For example:

\[
2d+3d=5d.
\]

Under this proposed operation, the numerator information is combined.

However, this is a **new algebraic rule**, not something that follows automatically from ordinary fractions.

---

# 32. The Zero Case in Addition

If:

\[
xd+(-x)d
\]

is defined using the previous rule, the numerator becomes:

\[
x+(-x)=0.
\]

Then:

\[
xd+(-x)d=0d.
\]

Using the special rule:

\[
0d=0.
\]

Therefore:

\[
\boxed{xd+(-x)d=0}.
\]

This would make the Divisionary objects behave somewhat like signed quantities under the proposed addition operation.

But this behavior must be regarded as an axiom of the new system.

---

# 33. Addition With Ordinary Numbers

A major design question is:

\[
5+3d=?
\]

There is no unique answer unless the system defines one.

A cautious approach would be to leave mixed operations as a separate category.

For example:

\[
5+3d
\]

could remain a symbolic mixed expression.

Another possibility would be to construct an algebra where ordinary numbers and Divisionary numbers coexist.

That would require additional axioms.

Therefore, the original Divisionary concept should not automatically assume:

\[
5+3d=8d
\]

because such a rule does not follow from the definition

\[
xd=x/0.
\]

---

# 34. Multiplication by Ordinary Numbers

Multiplication offers a more natural possible rule.

For ordinary \(a\), one could define:

\[
a(xd)=(ax)d.
\]

For example:

\[
2(5d)=10d.
\]

Conceptually:

\[
2\left(\frac50\right)
\]

can be represented as:

\[
\frac{10}{0}=10d.
\]

Again, this is a proposed algebraic extension rather than a theorem of ordinary division.

---

# 35. Multiplication by Zero

Now consider:

\[
0(xd).
\]

Using the proposed multiplication rule:

\[
0(xd)=(0x)d=0d.
\]

By the special rule:

\[
0d=0.
\]

Therefore:

\[
\boxed{0(xd)=0}.
\]

This is a potentially attractive property because it preserves the ordinary zero-multiplication law.

---

# 36. Multiplication of Two Divisionary Numbers

Now consider:

\[
(xd)(yd).
\]

This is much more complicated.

If one naively interprets:

\[
xd=\frac{x}{0}
\]

and

\[
yd=\frac{y}{0},
\]

then multiplication would seem to produce:

\[
\frac{x}{0}\frac{y}{0}
=
\frac{xy}{0^2}.
\]

But:

\[
0^2=0,
\]

so the expression becomes another division-by-zero expression.

One possible convention could be:

\[
(xd)(yd)=xy\,d.
\]

But this should be explicitly declared as an axiom if adopted.

It should not be claimed to be a direct consequence of ordinary fraction arithmetic.

---

# 37. Divisionary Powers

If multiplication is defined, one might ask about:

\[
(5d)^2.
\]

A possible rule would give:

\[
(5d)^2=25d.
\]

Similarly:

\[
(2d)^3=8d.
\]

However, this is a proposed algebraic behavior, not ordinary exponentiation of \(5/0\).

Therefore a rigorous system should clearly separate:

> ordinary arithmetic laws

from

> Divisionary algebra laws.

---

# 38. Divisionary Arithmetic Must Be Axiomatic

This is one of the most important mathematical requirements.

The definition

\[
xd=\frac{x}{0}
\]

only tells us what the symbol represents.

It does **not automatically define**:

\[
xd+yd
\]

\[
xd-yd
\]

\[
xd\cdot yd
\]

\[
\frac{xd}{y}
\]

or

\[
(xd)^n.
\]

Each operation requires a carefully chosen definition.

This is essential if the system is to become mathematically rigorous.

---

# 39. Equality Must Be Carefully Defined

The statement

\[
5d=5/0
\]

can mean "the Divisionary representation of \(5/0\)."

But equality should not be confused with ordinary numerical equality.

A robust notation might distinguish:

\[
5d\equiv\operatorname{Div}(5)
\]

from an ordinary equation.

This would make it clear that `5d` is a tagged representation.

---

# 40. The Most Important Non-Rule

The Divisionary system should **not** claim:

\[
5d\times0=5.
\]

That would contradict ordinary multiplication.

Instead, the system can say:

\[
5d\text{ represents }5/0.
\]

But representation does not imply that `5d` is an ordinary inverse of zero.

Therefore:

\[
5d\cdot0
\]

must be separately defined.

A conservative choice is:

\[
5d\cdot0=0.
\]

---

# 41. Divisionary Numbers Do Not Make Zero Invertible

This is perhaps the most important mathematical limitation.

Ordinary division by \(a\) can be understood as multiplication by \(1/a\):

\[
\frac{x}{a}=x\cdot\frac1a.
\]

For \(a=0\), there is no ordinary number \(1/0\) that acts as a multiplicative inverse of zero.

The Divisionary system does not change this.

It merely introduces a symbol:

\[
1d
\]

that represents the expression

\[
1/0.
\]

It should not be treated as an inverse satisfying:

\[
0(1d)=1.
\]

In fact, retaining:

\[
0(1d)=0
\]

would be much safer.

---

# 42. Why \(1d\) Is Not "The Inverse of Zero"

The notation

\[
1d=\frac10
\]

may visually resemble an inverse.

But:

\[
0(1d)\ne1.
\]

Therefore \(1d\) is not an ordinary multiplicative inverse of zero.

Instead:

\[
1d
\]

is a Divisionary representation of the forbidden quotient.

This distinction prevents the system from immediately collapsing into contradiction.

---

# 43. Divisionary Number Line

A conventional number line looks like:

\[
\cdots<-2<-1<0<1<2<\cdots
\]

Divisionary Numbers should not automatically be placed on this line.

Why?

Because they do not necessarily possess an ordinary real-number magnitude.

For example, asking whether:

\[
5d>10d
\]

may not have a meaningful answer.

The numerator identity tells us:

\[
5d\ne10d,
\]

but inequality is a separate concept.

Therefore an initial Divisionary system should define equality before defining order.

---

# 44. Magnitude Is Not Automatically Defined

It is tempting to say:

\[
|5d|=\frac50
\]

but that simply recreates the original problem.

A Divisionary Number does not automatically have a real-valued magnitude.

Thus:

\[
|5d|
\]

should remain undefined unless the system creates a new concept of Divisionary magnitude.

This is another example of why representation and evaluation must remain separate.

---

# 45. Limits and Divisionary Numbers

Consider:

\[
\lim_{x\to0}\frac{5}{x}.
\]

This is not automatically equal to \(5d\).

As \(x\) approaches zero from the positive side,

\[
\frac5x\to+\infty.
\]

From the negative side,

\[
\frac5x\to-\infty.
\]

Therefore the two-sided real limit does not exist as a finite real number.

The Divisionary representation:

\[
5d
\]

should not automatically replace the concept of a limit.

This distinction is essential.

---

# 46. Divisionary Numbers and Infinity

The system can therefore maintain three distinct ideas:

# 48. Divisionary Numbers and Indeterminate Forms

The expression:

\[

Other examples can diverge or fail to exist.

The proposed rule applies specifically to the Divisionary Number system.

## Axiom 5: No Inverse-of-Zero Rule

# 109. A Better Formal Definition

\]

The subscript or tag indicates that this pair belongs to the Divisionary domain.

Then:

\[
5d=\langle5,0\rangle_d.
\]

And:

\[

\]

Because:

\[
\langle5,0\rangle_d
\ne
\langle6,0\rangle_d,
\]

we obtain:

\[

\]

# 110. Divisionary Numbers as Ordered Pairs

A Divisionary object could deliberately preserve:

\[

\]

Thus:

\[

\]

could be regarded as:

\[
(5,0)_d.

The `d` tag says:

> "Do not interpret this pair using ordinary division."

This is an especially promising foundation for a formal theory.

Therefore:

This directly implements the original central idea.

# 129. A Key Design Principle: No Information Loss

The Divisionary system can therefore be described by the principle:

# 130. Infinite Cardinality

If every nonzero real number produces a unique Divisionary Number, then there are as many Divisionary Numbers as there are nonzero real numbers.

Therefore the Divisionary domain can be uncountably infinite if real numerators are allowed.

For integer numerators only, the set would be countably infinite:

\[
\ldots,-3d,-2d,-1d,1d,2d,3d,\ldots
\]

For real numerators, the domain becomes much larger.

# 135. The Special Role of Zero

The proposed system gives zero an unusual position.

For nonzero \(x\):

\[
x/0\rightarrow xd.
\]

But:

\[

\]

Therefore zero does not generate a separate nonzero Divisionary object.

This can be written:

\[
\boxed{0d=0}.
\]

The rule effectively identifies the zero Divisionary representation with ordinary zero.

# 136. The Zero Collapse Property

This could be called the **Zero Collapse Property**:

\[
\boxed{0d=0}.
\]

All nonzero Divisionary values remain distinct, while the zero case collapses into ordinary zero.

Thus:

\[
xd=yd
\]

only when:

\[

\]

for nonzero \(x,y\), while:

\[
0d=0.

# 137. A Possible Divisionary Identity

The system has an identity-like ordinary zero:

\[

\]

But it does not necessarily have a Divisionary multiplicative identity.

In particular, there is no reason to require:

\[

\]

to act like an ordinary one.

This again reinforces that Divisionary Numbers are not simply another copy of the real numbers.

# 138. Divisionary Arithmetic Is Not a Field

Because zero does not have an inverse, and because Divisionary values are exceptional tagged objects, the structure should not be called a field without a complete proof.

A safer description is:

> **a proposed extended arithmetic system containing Divisionary values.**

This is mathematically more accurate.

# 139. Divisionary Numbers and Algebraic Closure

The question of closure is interesting.

If:

\[

\]

then addition is closed over nonzero Divisionary values except where the numerator sum becomes zero.

If:

\[

\]

then the result returns to ordinary zero.

This creates a boundary between the Divisionary and ordinary parts of the system.

# 140. The Divisionary Boundary

One can imagine:

\[

\]

as a conceptual transition.

For example:

\[

\]

Thus opposite Divisionary labels can cancel under a proposed additive rule.

Whether this is desirable depends on the final algebraic design.

# 142. Two Versions of Divisionary Numbers

Version A is safer mathematically.

# 151. Potential Theorem: Distinctness

Assume the identity axiom:

\[
xd=yd\iff x=y.
\]

Then for any nonzero \(x\ne y\),

\[
xd\ne yd.
\]

### Proof

Suppose:

\[
xd=yd.
\]

By the identity axiom:

\[
x=y.
\]

But this contradicts:

\[
x\ne y.
\]

Therefore:

\[
xd\ne yd.
\]

Hence every distinct nonzero numerator produces a distinct Divisionary Number.

---

# 152. Potential Theorem: Zero Collapse

By definition:

\[
0d=0.
\]

Therefore the Divisionary representation of \(0/0\) is identified with ordinary zero.

Thus:

\[
\operatorname{Div}(0)=0.
\]

This is an axiom rather than a theorem of conventional arithmetic.

---

# 153. Potential Theorem: Nonzero Divisionary Values Are Not Ordinary Solutions

Let:

\[
xd=\frac{x}{0}
\]

for \(x\ne0\).

If \(xd\) were an ordinary number satisfying the definition of division, then:

\[
xd\cdot0=x.
\]

But ordinary multiplication gives:

\[
xd\cdot0=0.
\]

Therefore:

\[
0=x.
\]

This contradicts:

\[
x\ne0.
\]

Therefore \(xd\) cannot simultaneously be treated as an ordinary quotient satisfying the usual inverse property.

This theorem explains why Divisionary Numbers must be treated as special objects.

The most important insight of the proposal is not:

> "Division by zero has been solved."

> **"Division by zero can be represented without pretending it has an ordinary numerical solution."**

That is a much stronger and more defensible foundation.

# 155. Why the Idea Is Interesting

At first glance, the notation:

\[

But the underlying idea raises deep questions about what a number actually is.

The Divisionary concept answers these questions by separating **representation** from **evaluation**.

# 157. Final Definition

The proposed Divisionary Number system can be summarized formally as follows.

Let \(x\) be a number.

Define the Divisionary representation of division by zero as:

\[
\boxed{
\operatorname{Div}_0(x)=
\begin{cases}
0,&x=0,\\
xd,&x\ne0.
\end{cases}
}
\]

where:

\[
\boxed{xd\text{ represents }x/0}.
\]

The identity rule is:

\[
\boxed{xd=yd\iff x=y}
\]

for nonzero \(x,y\).

The system does not assert that \(xd\) is an ordinary real-number quotient.

# 158. Conclusion

Divisionary Numbers are a proposed mathematical notation for preserving the identity of expressions involving division by zero.

The fundamental notation is:

\[
\boxed{1d=\frac10}
\]

\[
\boxed{5d=\frac50}
\]

and, generally,

\[
\boxed{xd=\frac{x}{0}}.
\]

The defining characteristic is that different numerators produce different Divisionary values:

\[
1d\ne2d\ne3d\ne5d\ne100d.
\]

This prevents all division-by-zero expressions from being collapsed into a single value such as infinity.

The proposed system also introduces the special convention:

\[
\boxed{0d=0}
\]

corresponding to:

\[
\boxed{\frac00=0}
\]

within the Divisionary framework.

However, this convention must be distinguished from conventional mathematics, where \(0/0\) is undefined and is commonly treated as an indeterminate form in limit problems.

Most importantly, Divisionary Numbers do not need to claim that division by zero has been solved.

The notation can instead preserve the expression while leaving its ordinary arithmetic evaluation unavailable.

Thus:

\[
\frac50
\]

does not become the ordinary number \(5\).

It becomes the Divisionary representation:

\[
5d.
\]

Likewise:

\[
\frac{100}{0}
\]

becomes:

\[
100d.
\]

The central principle can therefore be stated one final time:

\[
\boxed{
\text{Divisionary Numbers represent division by zero; they do not pretend to solve it.}
}
\]

This makes the proposal fundamentally different from simply declaring:

\[
\frac{x}{0}=\infty.
\]

Instead of erasing the numerator, Divisionary notation preserves it.

Instead of changing ordinary arithmetic, it adds a new symbolic layer.

Instead of claiming that zero has an ordinary inverse, it explicitly avoids that contradiction.

And instead of forcing every undefined expression into one universal value, it maintains the identity of each zero-denominator expression.

In its most conservative form, Divisionary Numbers are therefore best understood as a **formal representation system for zero-denominator expressions**. In a more ambitious form, they could become the foundation for a new algebraic structure with its own operations, ordering, axioms, and computational implementation.

The notation begins with one remarkably simple rule:

\[
\boxed{xd=\frac{x}{0}}
\]

and one special convention:

\[
\boxed{0d=0}.
\]

From those two ideas emerges a potentially rich mathematical framework for studying the boundary between **defined arithmetic, undefined arithmetic, symbolic representation, and extended mathematical structures**.
