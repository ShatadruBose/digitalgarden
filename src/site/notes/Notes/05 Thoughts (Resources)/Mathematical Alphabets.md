# Mathematical Alphabets — Complete Reference

Mathematics does not use only the ordinary alphabet.

Different typefaces and alphabets are used to distinguish:
- Numbers and scalars
- Vectors
- Matrices
- Sets
- Fields
- Functions
- Operators
- Random variables
- Tensors
- Lie algebras
- Groups
- Spaces
- Constants
- Physical quantities
- Categories and objects
- Special mathematical structures

---

# 1. Ordinary Latin Alphabet

The normal Latin alphabet is used extensively in mathematics.

## Uppercase

ABCDEFGHIJKLMNOPQRSTUVWXYZ

## Lowercase

abcdefghijklmnopqrstuvwxyz

### Common examples

- `x` — variable
- `y` — variable
- `a, b, c` — constants or coefficients
- `f` — function
- `n` — natural-number index
- `A` — matrix or set
- `X` — random variable, set, or space
- `V` — vector space
- `R` — relation or matrix
- `P` — probability or proposition

# 43. Unicode Mathematical Alphabet Blocks

Unicode provides dedicated mathematical alphanumeric symbols in the range:

U+1D400 – U+1D7FF

These include many forms of:

- Latin letters
- Greek letters
- Bold
- Italic
- Bold italic
- Sans-serif
- Sans-serif bold
- Monospace
- Script
- Fraktur
- Double-struck

However, Unicode does NOT provide every possible combination of every mathematical font.

For serious mathematical typesetting, LaTeX/MathJax is usually better than Unicode.
